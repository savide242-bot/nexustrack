Política de Privacidade do NexusTrack

Última atualização: Outubro de 2026

1. Visão Geral

O NexusTrack é uma solução tecnológica de inteligência publicitária e monitorização de tráfego. Esta Política de Privacidade explica como tratamos os dados recolhidos através da nossa plataforma e pelas nossas integrações com redes como a Meta (Facebook Ads).

2. Dados Recolhidos e Finalidade

Acedemos aos seguintes dados para prestação dos serviços:

  • Meta Marketing API: Dados de leitura e gestão de campanhas publicitárias (gastos, cliques, impressões, conjuntos de anúncios e métricas de desempenho).
  • Dados de Rastreamento (Pixel & UTMs): Identificadores de cliques publicitários (como fbclid), parâmetros UTM de campanhas e eventos de navegação para atribuição de vendas.
  • Dados de Pagamento (Webhooks): Confirmação de status de vendas recebidas de gateways autorizados.

3. Uso e Partilha de Dados

Os dados obtidos através da Meta API são utilizados exclusivamente para exibição de métricas e relatórios ao próprio utilizador no painel do NexusTrack. Não vendemos nem partilhamos os seus dados com terceiros.

4. Eliminação de Dados

Para revogar o acesso ou solicitar a exclusão definitiva dos seus dados, o utilizador pode desconectar o perfil na aba de Integrações ou enviar um e-mail para suporte@nexustrack.app.
